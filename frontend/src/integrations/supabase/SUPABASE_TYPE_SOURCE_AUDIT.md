## Analysis

### Why Two Files?

The project has two Supabase type files:
- `types_utf8.ts` - older, corrupted with null bytes
- `database.types.ts` - newer, readable, likely regenerated by Supabase CLI

### Current Problem

All current imports use `types_utf8.ts`, which:
- Has encoding issues (null bytes)
- Cannot be read by tools
- Causes import errors in TypeScript/IDE
- Is likely outdated compared to `database.types.ts`

### Recommended Solution

**Standardize on `database.types.ts`** because:
1. It's readable and functional
2. It's likely the newly regenerated file from Supabase CLI
3. It's smaller (90KB vs 160KB), suggesting it's cleaner
4. It follows Supabase's standard naming convention
